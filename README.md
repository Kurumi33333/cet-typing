# CET Typing

一个专注 **CET-4 / CET-6 中译英主动输出**的本地优先打字训练项目。

## 目前可用的功能

- 渐进课程试验版：**8 个四级单元 + 4 个六级单元，共 120 个练习步骤**（110 个原创试验步骤 + 10 个有来源的开源例句精选）。从单词、语块循序渐进到句子。
- 句内逐词下划线输入、宽度提示、**任意点击词槽编辑**；空格 / 左右方向键自由换词；没有必须从左到右填写的限制。
- 判错与原位修正；**全部英文词槽刚拼对就立即跳到下一题**，无需 Enter、无成功停留。拼写有误或没有填完整时才需要手动检查和修改。
- Motion 题目切换、弹性进度和 **错误单词局部震动/红色光晕**；尊重系统减少动态效果设置。
- Web Audio 七类本地音效：**打字、删除、方向键移动、点击选格、答对、答错、下一题**。可关闭，设置保留在 localStorage。
- 选中格只更新下划线颜色，不展示点击水波纹和选择动画。题目切换时保留同一个输入 DOM 节点和焦点，减少移动端键盘收起。
- **V0.3 原生英语发音**：逐词由错/未填变为完全正确时调用 Web Speech API 的英语 TTS；同一正确状态不重复触发。拼错不读；快速输入不排长队；正确单词可重播；自动跳题后可从「声音」菜单重听上一句。自动发音设置独立于按键音效，可持久关闭。无需额外模型、音频文件或后端。
- **V0.5 FSRS 间隔复习**：错题首次进入到期队列；复习只按第一次独立回忆评分（Good / Again），修正过程不重复记高分。首页分别显示「到期」「未来」题数及下次复习时间，升级前保存的错题仍可复习。
- **独立四六级参考词库**：四级 7,508 原始行合并为 4,543 个唯一词条、六级 5,651 原始行合并为 3,991 个唯一词条。词库按需加载、支持中英文检索与系统英语发音，来源 [KyleBing/english-vocabulary](https://github.com/KyleBing/english-vocabulary)，BSD-3-Clause，完整许可见 `public/lexicon/LICENSE.txt`。**这些数据不是官方词纲，也不是自动生成的正式练习题。**
- **V0.4 本地学习记录**：用 Dexie + IndexedDB 保存四级/六级各自的课程断点、错题次数与纠错状态；重新打开能从上次练习继续；错题在复习中重新答对后移出待复习队列。
- **数据备份**：现为 V2 JSON，包含 FSRS 日期与状态；仍能导入旧 V1 备份。导入时校验格式并保留更新时间较新的记录，支持二次确认后清空本机记录。无云端同步。
- 全程纯前端；不接 Supabase，无账号，无远程保存记录。

在线预览：https://cet.theoryu.me

## 内容授权与限制

目前 120 步中 110 步为原创试验练习，10 步来自带出处的开源四级例句精选，**不是官方四六级真题、也没有覆盖完整词纲**。旧版 5+5 道演示题保留在 `src/data/starter.ts`，不再作为主线。不得未经许可复制第三方课程全文或资产。下一阶段计划筛选授权明确的词汇数据，再离线生产并校验可规模化的语块和例句。

## 英文直输键盘（2026-10-18）

- **电脑物理键盘**：练习区聚焦时监听 `keydown` 的物理 `KeyA`–`KeyZ` 键位，立即直接写入拉丁字母；即使 Windows 拼音输入法报 `key=Process`、`isComposing=true` / `keyCode=229`，浏览器只要仍提供可靠 `code` 就会绕过选词。支持 Shift、删除、空格、Enter、方向键；快捷键（Ctrl / Alt / Meta）不截获。
- **手机触屏**：默认启用**网页内置英文 QWERTY**，通过点击 26 个英文字母直接录入，不调用拼音候选词，不依赖系统中文输入法设置；提供大小写、退格、下一词、Enter 以及撇号/连字符。可通过「使用系统键盘」改回原生软键盘，偏好保存在本设备浏览器。
- **系统键盘回退**：输入框标记 `lang=en`、禁自动纠错/大小写，`inputmode=text` 是浏览器键盘布局的提示，**不能控制/强迫 iOS、Android 或第三方输入法切换中英文**。若系统软键盘不提供单个英文字母键事件，请用内置英文键盘。
- **安全兼容**：不接收中文上屏作为英文答案；拦截物理键位后不会再重复提交 IME 的组合结果。选中词槽、TTS、FSRS 与连续换题焦点保持不变。
- **验证范围**：Chromium 浏览器中验证模拟中文 IME 的 Process/229 键盘事件、手机模拟触屏的按键（快速、慢速）、退格、模式切换与题目推进。**真实 iPhone/第三方拼音键盘仍需手动验证**，网页没有操作系统输入法设置权限。

## V0.7 · 一屏布局与即时判题

- 首页、练习页、词汇检索页、单元完成页都使用 `100svh` 自适应视口容器，优先显示完整操作区。可见内容不依赖页面纵向滚动，也不展示页面滚动条。
- 手机默认内置英文键盘。按照屏幕高度调整字距、键高、题目留白；已检查 320×568、390×844 的模拟触屏布局，包括 11 词的长句及展开的课程/工具菜单。
- 词汇查询改为每页 3–6 条结果，最多仍检索 30 个匹配词条，用翻页代替滚动；原始词库并未删除。
- 答案逻辑使用 `allSlotsCorrect`：任何输入路径（物理键盘、系统输入框、网页英文键盘）只要**所有**单词的目标拼写全部匹配，即刻完成并跳到下一题。单词过短、漏填、错字或额外输入均不会触发。
- 即时成功由同一输入事件完成次数统计及 FSRS 回忆判定；保留最后一个词的 TTS 发音，不再播放需要等待的成功页；复习首次已答错后修正不会被误打为 Good。
- iPhone/Android **真实系统键盘弹出后可能调整可视窗口**，网页无法控制系统输入法或浏览器地址栏行为；真机仍需覆盖验证。极短横屏视口可能需要设备旋转到竖屏。


## 拼音输入法候选框抑制（2026-10-18）

- 电脑默认「英文直输 · 防拼音候选」：把唯一的可聚焦文本输入框设为 `readOnly` + `inputMode=none`，不允许浏览器启动原生文本编辑；监听物理按键的 `KeyboardEvent.code`，用程序直接维护下划线词槽。这样不仅跳过中文候选词**上屏**，也能在主流浏览器中避免唤起拼音编辑/候选界面。
- `readOnly` 仍可获得焦点，与 `disabled` 不同。单词点击重选后第一字母覆盖旧词，后续字符追加；空格换槽、删除、Shift、完成后 360ms 视觉确认保持正常。
- 「设置」→「系统输入 · 兼容模式」可恢复原生可编辑输入框，方便粘贴、特殊辅助输入或遇到设备兼容问题。偏好保存在 `cet-typing:desktop-input-mode`。
- 手机触屏保持默认网页英文键盘；主动切回系统拼音键盘时，**网页无权关闭第三方输入法的候选条**。`inputmode` 只是一种布局提示，并非切换系统输入法的控制指令。
- 自动验收覆盖 Chromium 模拟 `Process`、`code=KeyI`、连续 `like` 输入、点击已输入单词并覆盖、模式切换、390px 网页键盘；**真实 Windows 微软拼音/搜狗、macOS 拼音仍需人工确认候选窗在设备上不弹出**。部分输入法可能不提供物理 `code`，此时必须用系统输入兼容模式。


## 可接受的多种译法 · V0.9（2026-10-18）

中译英的正常答案并非唯一，**完整英文字符串等于预设目标**不等于**语义唯一正确**。现有试验题库已为 46 道 CET4/CET6 练习逐条登记 50 个保守核验的替代表达（`src/data/acceptedAnswers.ts`），示例：

- 保持健康：`stay healthy`、`keep healthy`、`remain healthy`、`maintain good health`。其中 `stay healthy` 更常用；`keep healthy` 在英式用法中可接受。没有把强调体能的 `keep fit` 直接当作完全同义。
- 乘公交车：`by bus`、`take a bus`、`take the bus`。
- 每天：`every day`、`daily`。
- 节约能源：`save energy`、`conserve energy`。
- 充足的证据：`sufficient evidence`、`enough evidence`。

技术：不同长度的合法答案根据已输入字词自动采用正确词槽数；区分前缀与完整正确答案；只有显式列入审校清单的表达会自动通过并保留原生 TTS 和 360ms 的绿色确认。不采用模糊匹配，也不会把拼写错误自动视为同义词。

**局限：** 这只是人工/模型辅助初步审核过的一批备选，不是语义判题模型，更不是完整、官方或教师认证的自由翻译语料。未收录的合理译法仍可能无法自动通过，问题会以「目标表达不同」处理；CET4 既有风险题与 CET6 多词题不会因为这种不确定性自动累积普通练习 FSRS 错题。详情：`docs/CET_MULTI_ANSWER_REVIEW.md`。
