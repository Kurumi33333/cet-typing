# CET Typing

一个专注 **CET-4 / CET-6 中译英主动输出**的本地优先打字训练项目。

## 目前可用的功能

- 渐进课程试验版：**4 个四级单元 + 3 个六级单元，共 70 个原创练习步骤**。从单词、语块循序渐进到句子。
- 句内逐词下划线输入、宽度提示、错误词定位、修正与自动下一题。
- Motion 题目切换、弹性进度和 **错误单词局部震动/红色光晕**；尊重系统减少动态效果设置。
- Web Audio 本地合成成功/错误短音，可一键关闭，开关记在浏览器 localStorage。
- 全程纯前端；不接 Supabase，无账号，无远程保存记录。

在线预览：https://cet.theoryu.me

## 内容授权与限制

当前 70 条课程是自行编排、用于验证教学递进和交互的演示练习，**不是官方四六级真题、也没有覆盖完整词纲**。旧版 5+5 道演示题保留在 `src/data/starter.ts`，不再作为主线。不得未经许可复制第三方课程全文或资产。下一阶段计划筛选授权明确的词汇数据，再离线生产并校验可规模化的语块和例句。

## 本地运行

Node.js 20.19+ 或 22.12+：

```bash
npm install
npm run dev
```

```bash
npm run typecheck
npm test
npm run build
```

Cloudflare Pages 连接 `main`，每次推送自动执行测试、类型检查和生产构建。分步开发计划见 [ROADMAP](docs/ROADMAP.md)。
