# CET Typing

一个专注 **CET-4 / CET-6 中译英主动输出**的本地优先打字训练项目。

## 目前可用的功能

- 渐进课程试验版：**6 个四级单元 + 4 个六级单元，共 110 个原创练习步骤**。从单词、语块循序渐进到句子。
- 句内逐词下划线输入、宽度提示、**任意点击词槽编辑**；空格 / 左右方向键自由换词；没有必须从左到右填写的限制。
- 判错与原位修正；答对后按 **Enter** 立即下一题（也支持短暂停留后自动前进）。
- Motion 题目切换、弹性进度和 **错误单词局部震动/红色光晕**；尊重系统减少动态效果设置。
- Web Audio 七类本地音效：**打字、删除、方向键移动、点击选格、答对、答错、下一题**。可关闭，设置保留在 localStorage。
- 选中格只更新下划线颜色，不展示点击水波纹和选择动画。题目切换时保留同一个输入 DOM 节点和焦点，减少移动端键盘收起。
- **V0.3 原生英语发音**：逐词由错/未填变为完全正确时调用 Web Speech API 的英语 TTS；同一正确状态不重复触发。拼错不读；快速输入不排长队；正确单词可重播，答对后可手动朗读整句。自动发音设置独立于按键音效，可持久关闭。无需额外模型、音频文件或后端。
- **V0.5 FSRS 间隔复习**：错题首次进入到期队列；复习只按第一次独立回忆评分（Good / Again），修正过程不重复记高分。首页分别显示「到期」「未来」题数及下次复习时间，升级前保存的错题仍可复习。
- **独立四六级参考词库**：四级 7,508 原始行合并为 4,543 个唯一词条、六级 5,651 原始行合并为 3,991 个唯一词条。词库按需加载、支持中英文检索与系统英语发音，来源 [KyleBing/english-vocabulary](https://github.com/KyleBing/english-vocabulary)，BSD-3-Clause，完整许可见 `public/lexicon/LICENSE.txt`。**这些数据不是官方词纲，也不是自动生成的正式练习题。**
- **V0.4 本地学习记录**：用 Dexie + IndexedDB 保存四级/六级各自的课程断点、错题次数与纠错状态；重新打开能从上次练习继续；错题在复习中重新答对后移出待复习队列。
- **数据备份**：现为 V2 JSON，包含 FSRS 日期与状态；仍能导入旧 V1 备份。导入时校验格式并保留更新时间较新的记录，支持二次确认后清空本机记录。无云端同步。
- 全程纯前端；不接 Supabase，无账号，无远程保存记录。

在线预览：https://cet.theoryu.me

## 内容授权与限制

当前 110 条渐进课程是自行编排、用于验证教学递进和交互的演示练习，**不是官方四六级真题、也没有覆盖完整词纲**。旧版 5+5 道演示题保留在 `src/data/starter.ts`，不再作为主线。不得未经许可复制第三方课程全文或资产。下一阶段计划筛选授权明确的词汇数据，再离线生产并校验可规模化的语块和例句。

## 本地运行

Node.js 20.19+ 或 22.12+：

```bash
npm install
npm run dev
```

```bash
npm run typecheck
npm test
npm run validate:vocab
npm run build
```

Cloudflare Pages 连接 `main`，每次推送自动执行测试、类型检查和生产构建。分步开发计划见 [ROADMAP](docs/ROADMAP.md)。
