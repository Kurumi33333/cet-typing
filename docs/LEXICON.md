# 词库来源与边界

- 上游：KyleBing/english-vocabulary（https://github.com/KyleBing/english-vocabulary）。
- 许可：BSD-3-Clause。完整版权声明及授权条款放在 `public/lexicon/LICENSE.txt`，部署中原样保留。
- 原始数据：`3 四级-乱序.txt` 与 `4 六级-乱序.txt` 的「词条 + 中文释义」。
- 处理：同一个英文词条去重并合并不同中文释义，不直接搬运例句、真题或不明授权内容。
- 数据状态：**公开开源参考词表，不保证等同官方最新四/六级考试词纲**；不能将未经校对的歧义释义直接用于唯一答案的中译英练习。
- 教学设计：基础词表首先用于检索/辅助内容编排。进入正式练习前应逐条审校中文义项、歧义与常用程度，再制作词→语块→句子的渐进课程。
- 不要在常规首屏打包整个词库，按需加载静态 JSON。

## 2026-10-18 CET-4 二次核验（审计，不是认证）

- 可复现的上游源码：`KyleBing/english-vocabulary@c4c6c80879ff17d7025c28fb853a4991c8e6be6a`，默认分支 `master`；四级源文件 blob `582c021ead732e48f0428991a58c9eff72380ccf`，许可证 blob `4974c0ec054bba1b76aa1df0c03b220aa31f82e9`。上游仓库最近推送于 2026-09-30，但**代码更新日期不等于大纲修订日期或词义准确性证明**。
- `cet4.json`：原始 **7508 行**，按英文词头合并后 **4543 词头**、**7390 条释义字符串**；其中 **2261 个词头有多条释义**。源码的多个释义常有交叉、重复、不同词性或解释方式，**不构成“7390 个已验证独立词义”**。
- 自动基础检查：词头去重、文本非空、含中文释义、词头格式；本批未出现释义完全无中文字或长于 120 字的记录。**格式检查不代表词义无误。**
- 与当前 23 个四级单词练习逐一比对：`tea`、`you`、`time`、`understand`、`tomorrow` 在参考词表**缺失**。这是对开源词表覆盖不足的证据，不表示这些基础词不属于四级。
- 截至核对日，[教育部教育考试院 CET 官网考试大纲](https://cet.neea.edu.cn/html1/folder/16113/1588-1.htm) 仍列出《全国大学英语四、六级考试大纲（2016年修订版）》；[2026-08-13 重印的清华大学出版社四级词汇书](https://www.tup.tsinghua.edu.cn/booksCenter/book_10653101.html) 也明确以 2016 版为依据。出版社所述接近 5000 词、1000 词组，**不可据此推算本站 4543 词头的覆盖率**：收词、词形及短语口径不同，且没有得到官方全词表的一对一对照。
- [考试院 CET4 笔试结构](https://cet.neea.edu.cn/xhtml1/report/16123/196-1.htm)：翻译部分为**汉译英段落翻译**，占 15%；本站的单词→短语→短句打字只能作为基础能力训练，不能当真实翻译得分预测。
- 2026 年附近的题材趋势仅用于**课程场景选材**，不可把网络营销文章中的热点预测/百分比当作官方命题频率；不得批量复制考试真题或付费教材。

### 开发硬约束

1. 上游词表仅用于查询及待审校候选，不直接生成“词义唯一”的自动评分题。
2. 全部新四级练习必须登记审校状态、替代译法风险和缺失词头。
3. 只有逐项完成**词义核验 → 自然例句/语境 → 多解审查 → 复核记录**的练习，才能在产品文案中称作高保真题库内容。
4. 随后再增添“最新版”资料，必须先验证教育部教育考试院正式发布的修订通知，而不是依据 GitHub 的仓库名/更新时间推断。
