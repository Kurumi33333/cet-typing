# CET Typing · 小步开发路线

## 项目边界
- 核心：CET-4/CET-6 中译英主动输出、逐词纠错、渐进式语块练习。
- 本地优先：不接 Supabase、不要求登录。用户数据未来存 IndexedDB，设置放 localStorage。
- 静态题库：先使用少量自编示例，后续独立生成、审核并导入授权词表与例句。
- 不复制句乐部品牌、界面资产或未确认授权的教材内容。Earthworm 仅作思路参考。
- 每阶段单独提交、独立验证；不一次性进行跨阶段大规模迁移。

## 阶段与验收标准
- [x] S0 · 工程骨架：Vite + React + TypeScript 文件已提交；目录与边界明确。
- [x] S1 · 最小闭环（代码已实现）：CET4/6 各 5 道自编示例；输入、提交、对错提示、下一题、结算。运行验证见下文。
- [ ] S2 · 输入引擎：输入法兼容、逐词标注、错词修正、快捷键及单元测试。
- [ ] S3 · 题库模型：CET4/6 分层，句子/语块/练习步骤标准结构，静态 JSON 校验和加载。
- [ ] S4 · 本地持久化：Dexie/IndexedDB 进度、错题和导入导出。
- [ ] S5 · 复习调度：ts-fsrs 集成，复习队列与学习统计。
- [ ] S6 · 内容生产：合规词表导入、AI 离线拆分、数据质量审查。
- [ ] S7 · 体验与交付：键盘手感、动效、无障碍、移动端及 Cloudflare Pages 部署。

## 计划目录
- `src/features/practice/`：交互组件和练习状态机
- `src/features/course/`：题库加载、内容模型
- `src/features/review/`：FSRS 和复习界面
- `src/lib/storage/`：持久化适配层
- `src/data/`：已审核静态示例/课程
- `content-pipeline/`：离线内容导入、拆分、校验
- `docs/`：进度和架构说明

目录将在对应阶段落地，不为了占位创建空文件。
