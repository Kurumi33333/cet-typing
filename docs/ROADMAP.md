# CET Typing · 开发路线

## 约束
- **本地优先**：React + Vite + TS；不接 Supabase、无登录；复习进度后续由 Dexie/IndexedDB 保存。
- **课程优先**：先保证单词 → 语块 → 句子逐渐升级，不要直接从完整长句起步。
- **题库合规**：只用原创文本或审查过许可的外部数据，不搬运句乐部/ Earthworm 课程或视觉资产。
- **小步提交**：各批独立进展、以 CF 构建验证为准。

## 已做验证（2026-10-18）
- Cloudflare Pages 连接 `main`，运行 `npm run build`，含 Vitest + TypeScript + Vite。
- 最新交互版构建：**5 个测试文件 / 26 个单元测试通过；生产部署 success**。
- 通过 Cloudflare 真实浏览器验证：第一题 `我 → I` 自动切换 `喜欢`，下题输入焦点恢复。
- 验证四级单元下拉数量为 4、静音按钮写入 `localStorage`、错误单词原位标红且带 Motion transform。
- 390px 浏览器回归：先选第三格再返回第二格/第一格填词、空格导航、错误状态选择任意格、Enter 立即下一题；无横向溢出。
- 输入节点跨题 `===` 恒等、焦点保持；浏览器拦截 AudioContext 确认打字和方向键实际创建声音节点。**真实 iOS 软键盘是否始终可见仍需设备端实测**。
- 尚未完成全课程人工校对、全部真实输入法/移动端键盘/系统浏览器覆盖；这些不得标记为通过。
